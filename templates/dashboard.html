⌘ API & intégration externe

Chaque bot enregistré reçoit sa propre clé API. Tu peux l'utiliser depuis un autre programme ou un autre bot que tu contrôles. Garde la clé privée et transmets-la uniquement côté serveur.

Endpoint : POST /v1/download
En-tête : X-API-Key: TA_CLE_API
Corps JSON : {"url":"https://..."}

La réponse contient ok, platform, title et items. Les clés API ne sont affichées qu'une seule fois lors de leur création ou rotation.

🛡️ Sécurité & stockage

Les tokens Telegram sont chiffrés côté serveur. Les clés API et secrets webhook sont stockés sous forme d'empreintes, et les secrets webhook sont vérifiés à chaque événement. Les données des bots sont conservées dans PostgreSQL, pas dans le système de fichiers temporaire de Vercel.
